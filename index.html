Commodity Disruption Signal & Explanation System

An AI-driven risk-monitoring pipeline for supply-chain and procurement teams. It flags significant arabica coffee price anomalies and explains them using cited public evidence.

Data
Integrating five public sources (NOAA weather, GDELT news, Freightos shipping, World Bank and FRED macro), each on its own daily-to-monthly schedule, into one timezone-normalized dataset. Every value is stamped with its release date to prevent lookahead bias.
Detection
Flagging anomalies with a rolling-volatility z-score over a 60–90 day window instead of a fixed percentage threshold. The forecast model must beat a naive baseline under walk-forward validation.
Explanation
Designing a RAG layer on a FAISS vector index with relevance gating. The LLM must cite retrieved evidence or return “insufficient evidence”, which cuts hallucinated explanations.
Delivery
Shipping a Streamlit dashboard and a daily scheduled pipeline on GitHub Actions with logging. Measuring precision, recall and false-positive rate on historical disruptions and on no-event control periods.

Python, FastAPI, JavaScript, Gemini API, SQLite
